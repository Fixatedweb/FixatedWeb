FIXATED CANNABIS - website files

Open index.html in a browser, or in VS Code install the "Live Server" extension,
right-click index.html and choose "Open with Live Server".

Files
  index.html   page structure
  styles.css   all styling and colours (colours are at the top, under :root)
  app.js       pages, shop, bag, checkout (orders go to WhatsApp)
  data.js      products, prices, stock, phone numbers, delivery text
  images/      product photos

To change a price or mark something sold out, edit data.js ("price" and "stock").

Note: the Owner panel (footer > Owner login) only works on claude.ai. On your own
computer or host, edit data.js instead.
